AWS Unit 3 — Linux EC2 Deployment

Aim

To launch and configure a Linux EC2 instance on Amazon Web Services (AWS) and understand basic cloud infrastructure and remote access security.

Objectives

- Launch a Linux virtual machine using Amazon EC2.
- Configure security groups to control incoming network traffic.
- Verify EC2 instance status checks.
- Understand secure remote access to a Linux instance.
- Learn basic AWS cloud security practices.

Tools and Technologies

- Amazon Web Services (AWS)
- Amazon EC2
- Linux (Amazon Linux, if used in the lab)
- Security Groups
- SSH (Secure Shell)

Procedure

Step 1: Launch an EC2 Instance

Opened the AWS Management Console and navigated to Amazon EC2. Configured and launched a Linux instance with the required instance settings.

Step 2: Configure the Security Group

Configured the instance security group to control incoming traffic. SSH access uses TCP port 22 and should be restricted to the user's trusted IP address.

Step 3: Verify Instance Status

Checked the EC2 console to confirm the instance state and status checks.

Step 4: Connect to the Linux Instance

Attempted or established SSH access to the Linux instance using the configured connection method. Add evidence of the connection if available.

Security Practices

- Restrict SSH access to trusted IP addresses.
- Keep private keys and AWS credentials secure.
- Allow only the network traffic required for the lab.
- Review security group rules regularly.
- Stop the instance when it is no longer needed.

Results

The lab covers Linux EC2 deployment, security group configuration, instance status verification, and SSH-based remote access. Include only the steps successfully completed and supported by your screenshots.

Conclusion

This lab provides practical experience with Linux virtual machines on AWS and demonstrates the importance of configuring network access securely.
